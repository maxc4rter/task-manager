# Task Manager

Простое приложение для управления задачами (Python, Tkinter, ООП).

## Запуск
1. Установите Python 3.x (Tkinter входит в стандартную установку).
2. Скачайте или клонируйте репозиторий.
3. Запустите файл `gui.py`:
   `python gui.py`

## Использование
- Введите название, описание и срок выполнения (формат `ГГГГ-ММ-ДД`), нажмите «Добавить задачу».
- Чтобы удалить задачу, выберите её в списке и нажмите «Удалить задачу».

## Функциональность
- Добавление и удаление задач.
- Автосохранение в файл `tasks.json` и загрузка при запуске.

## Структура проекта
- `classes.py` - классы `Task` и `TaskManager`.
- `gui.py` - графический интерфейс на Tkinter.
- `tasks.json` - файл с сохранёнными задачами.
